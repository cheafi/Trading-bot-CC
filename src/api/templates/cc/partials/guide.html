這一頁是說明書，不是下單畫面。Reference-only — 真正報價同「今日可唔可以買」以 Dashboard 為準。
每日 5 步 · Daily flow
  1. Dashboard — 今日適唔適合買股？（WAIT = 先休息）
  2. Playbook — 系統排好嘅候選名單
  3. Dossier — 睇一隻：買入區、止蝕、理由
  4. Portfolio — 倉位會唔會太重？
  5. IBKR — 真係要落單先開
⚡ 三條鐵律 · Three rules
  • 今日大環境 > 單一靚卡 — Dashboard 話 WAIT，就唔好因為一隻股高分而硬買。
  • 研究頁 ≠ 准買證 — 探索、資金流、基金、策略實驗室只係做功課。
  • 要有止蝕先算計劃 — 冇清晰買入區 + 止蝕，當「觀察」，唔好計倉位。
幾時可以動錢？幾時要停？
可以考慮
Dashboard 非 WAIT · 數據正常 · Playbook 標示 TRADE 且有止蝕 · IBKR 已 READY（唔係淨係 LOGIN）
要停
WAIT / NO_TRADE · 數據過期 · 券商未連好 · 只有研究分、冇完整價位
📖 各頁做乜 · What each tab does 展開
🔝 Header bar — 4 layers
頂部狀態睇四樣：數據新唔新、引擎有冇跑、券商連唔連到、今日允唔允許買。
① Market data status
REAL_TIME DATA FRESH STALE SYNTHETIC
⚠ STALE / CRITICAL / SYNTHETIC — treat all prices and scores as provisional until DATA FRESH returns.
② Engine status
LIVE PAPER OFF BREAKER
Confirm in header and Ops when freshness matters. LIVE/PAPER badge alone is not always proof a fresh runtime cycle completed. OFF = stale decisions. BREAKER blocks new entries.
③ Broker status
READY PAPER DISCONNECTED
Gateway may show LOGIN or GATEWAY UP · LOGIN REQUIRED — transport up, session not active. Execution-ready requires READY + account + bracket alignment, not Connect alone.
④ Execution readiness
STRONG_TRADE TRADE SELECTIVE WAIT NO_TRADE
Dashboard tradeability banner + per-card execution_ready flag. WAIT/NO_TRADE days: patience is the active decision.
Trust strip (below nav): regime (BULL/SIDEWAYS/CHOPPY/BEAR), VIX, breadth, and confidence bar. In BEAR or CHOPPY, board gates often downgrade cards to WAIT/AVOID even when individual scores look fine.

🗂 Three surface types
Core decision Core
Dashboard · Playbook · Portfolio & Risk · Search / Dossier — deploy/no-deploy, sizing, per-ticker verdicts.
Research / supporting Research-only
Discovery · Funds · Flow · RS — idea generation and context; not trade permission alone.
Diagnostic / execution Diagnostic Execution-dependent
IBKR · Ops · Rejections · Guide — handoff, health/jobs, blocker audit. Ops confirms runtime; IBKR required for live sends.
🛑 幾時唔好買
  • Dashboard 話 WAIT / NO_TRADE
  • 數據過期或引擎未跑
  • IBKR 未 READY（淨係 LOGIN 唔算）
  • 冇止蝕 / 只有研究分
  • 回測、資金流、AI 故事 — 唔可以單獨做買入理由
